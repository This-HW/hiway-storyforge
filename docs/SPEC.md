## 1. 배경과 문제 정의

인스타그램 사진 보너스 모델의 제작 공정은 단순하다: 해외에서 검증된 사진 소재를 골라, 한국인이 멈춰 볼 후킹 문장 한 줄을 얹어 게시하는 것. 그러나 실제로는 매 게시물마다 아래 6단계를 손으로 반복해야 하고, 여기서 시간이 새고 품질이 흔들린다.

1. 소재의 핵심 사실 파악 (사진이 말하는 이야기가 무엇인가)
2. 후킹 문장 작성 (번역체 제거, 규칙 적용, 길이 제한)
3. 이미지 합성 (문장을 사진에 얹는 템플릿 작업)
4. 다국어 버전 제작 (국가별 현지화)
5. 정책·권리 검수 (게시 전 체크)
6. 기록 (무엇을 만들었고, 출처가 어디이며, 성과가 어땠는지)

이 도구는 1~6을 한 화면 흐름으로 묶어, 소재 1건당 제작 시간을 **5분 이내**로 줄이는 것이 목표다. (강의 자료가 주장하는 제작 시간과 같은 목표치)

## 2. 범위

### 만든다 (In scope)
- 소재 등록·관리 (이미지 + 출처·권리 상태 기록)
- 소재 분석 보조 (이미지에서 핵심 사실 1개 추출)
- 후킹 카피 후보 생성·선택·편집 (한국어 원본 + 다국어 현지화)
- 템플릿 기반 이미지 합성·미리보기
- 게시 전 검수 (정책 금지 항목·형식 규칙 자동 체크 + 수동 확인 항목)
- 게시 패키지 내보내기 (이미지 + 캡션 초안 + 기록)
- 제작 이력·성과 기록 (게시 후 조회수 입력欄)

### 만들지 않는다 (Out of scope)
- 인스타그램 자동 게시·자동 로그인 — 정책 리스크가 크고, 보너스 초대와 무관하다. 게시는 사용자가 직접 한다
- 해외 소재 자동 크롤링/스크래핑 — 권리 확인이 불가능한 수집은 검수 원칙과 충돌한다. 소재는 사용자가 가져와 등록한다 (P2에서 "후보 수집 보조"를 별도 검토)
- 보너스 초대·수익 보장 관련 기능 — Meta 소관이며 도구로 다룰 수 없다
- 다중 사용자·계정 공유 — 1인 사용 전제

## 3. 사용자

- 사용자 1인 (HW). 웹 UI로 접속해 직접 조작한다 (CLI 전제 아님)
- 사용 환경: 로컬 우선. 데이터(소재·기록)는 로컬에 저장된다

## 4. 용어

| 용어 | 뜻 |
|---|---|
| 소재 | 게시물의 바탕이 되는 사진 1장과 그 이야기(핵심 사실). 해외 바이럴 사진이 전형적 |
| 핵심 사실 | 소재에서 뽑은 단 하나의 사실·사건. 카피는 이것만으로 만든다 |
| 후킹 카피 | 사진 위에 얹는 15~28자, 최대 2줄의 문장. 직역이 아닌 "편집"의 결과물 |
| 현지화 | 다른 언어권용 카피를 직역이 아니라 그 언어의 후킹 문장으로 다시 쓰는 것 |
| 게시 패키지 | 완성 이미지(+언어별 버전) + 캡션 초안 + 소재 메타데이터의 묶음 |
| 검수 | 게시 전 정책·권리·형식 체크. 자동 판정 항목과 수동 확인 항목으로 나뉜다 |

## 5. 전체 플로우

```
[소재 등록] → [분석: 핵심 사실 확인] → [카피 생성: 후보 중 선택·편집]
→ [합성: 템플릿 미리보기] → [현지화: 언어별 버전 생성·확인]
→ [검수: 자동 체크 + 수동 확인] → [내보내기: 게시 패키지] → [기록: 게시 후 조회수 입력]
```

- 어느 단계에서든 이전 단계로 돌아갈 수 있다.
- 검수를 통과하지 못한 소재는 내보내기가 잠긴다 (수동 확인 항목은 사용자가 "확인함"으로 명시해야 통과).

## 6. 기능 요구사항

### FR-1 소재 등록·관리
- 이미지 파일 업로드 (JPG/PNG). 등록 시 아래 메타데이터를 함께 기록한다:
  - 출처 (URL 또는 설명) — **필수**. 없으면 등록 불가
  - 권리 상태: `확인됨 / 불명확 / 사용불가` — **필수**. `사용불가`는 이후 단계 진행 불가
  - 넓은 주제 태그 1개 (아래 15개 중 선택): 운동, 동물, 우주, 음식·요리, 건강, 연예·남녀관계, 가족, 직장, 돈·경제, 자동차·교통, 군대·남자공감, 여행, 학교·학창시절, 결혼, 소비·생활
  - 원본 언어/국가 (선택)
- 소재 목록: 상태별 필터 (등록됨 / 제작중 / 검수대기 / 완성 / 게시완료), 주제별 필터
- 소재 상태는 플로우 진행에 따라 자동 전이된다

### FR-2 소재 분석 보조
- 등록된 이미지를 비전 모델로 분석해 **핵심 사실 후보 1~3개**를 문장으로 제시한다
- 사용자는 후보를 선택하거나 직접 수정·입력한다. **핵심 사실이 확정되지 않으면 카피 생성으로 넘어갈 수 없다**
- 분석 결과에는 "사진에 이미 보이는 정보" 목록도 함께 제시한다 (카피에서 지워야 할 정보 — FR-3 규칙 R2의 재료)

### FR-3 후킹 카피 생성 (핵심 기능)
- 입력: 확정된 핵심 사실 + 주제 태그 + 톤 옵션 (유머 강도: 없음/한 스푼)
- 출력: 카피 후보 **5개**, 각 후보에 적용된 변환 포인트를 한 줄로 표시 (예: "결과 앞배치", "숫자 구체화")
- 생성 규칙 (시크릿노트 후킹 공식의 규칙화):
  - R1 핵심 사실 하나만 남긴다. 부연·배경 설명 금지
  - R2 사진이 이미 보여주는 정보는 카피에 넣지 않는다 (FR-2의 목록 활용)
  - R3 기사체·번역체 금지, 한국인이 실제 쓰는 구어체 단어만 사용
  - R4 조사·수식어를 걷어낸다. 빈 수식어("매우 놀라운") 대신 구체적 사건·수치·결과로 쓴다
  - R5 **15~28자, 최대 2줄**. 가장 강한 결과·반전·유머를 문장 앞에 배치한다
  - R6 유머는 옵션 켤 때만 한 스푼. 사실 왜곡은 유머로도 금지
- 형식 검증은 자동이다: 글자 수·줄 수 초과 후보는 생성 즉시 표시하고, 확정 시에는 제한을 만족해야 한다
- 사용자는 후보 선택 후 직접 편집할 수 있다. 편집본도 같은 형식 검증을 받는다

### FR-12 스토리 캐러셀 (2026-10-21 추가, HW 지적 + 운영 판단)
- 배경: 무료 전자책은 "한 장짜리 후킹 이미지"와 "캐러셀형 정리 이미지"를 모두 유효 형식으로 명시한다 (전자책 p.15). 구체 구성법은 유료 강의 영역이라 자료에 없으므로, 운영 형식은 운영자가 정한다: **스토리형 캐러셀을 주력**으로 한다 (넘겨보기·저장·체류가 보너스 모델의 핵심 변수이기 때문).
