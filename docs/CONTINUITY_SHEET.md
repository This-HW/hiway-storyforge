# 연속성 시트 (Continuity Sheet) — 스토리 캐러셀 제작용

건마다 제작 전에 이 시트를 먼저 확정한다. 시트에 적힌 값은 전 슬라이드
프롬프트에 그대로(verbatim) 들어가고, 장면 프롬프트에서는 외형을
다시 묘사하지 않는다 (하이웨이 스튜디오 ADR-0011 §4 규칙 차용:
정체성은 레퍼런스가 잡고, 프롬프트는 바뀌는 것만 묘사한다).
