# 사진 보너스 운영 플레이북 v0.1

- 작성일: 2026-10-21
- 성격: 유마드 4기 커리큘럼(1·2·4주차 방법론)을 무료 자료 + Meta 공식 정책만으로 재구성한 실행 문서. 강의 원본이 아니라 동등 기능을 노린 자체 운영법이다
- 근거: 전자책 28p, 시크릿노트 9p, Meta 공식 보너스 규칙 (초대제·지역별 월 최소 조회수·지급 제외 규칙)
- 짝 문서: hiway-storyforge 스펙 (docs/SPEC.md) — 이 문서의 "제작" 단계는 제작기가 담당한다

---

## 0. 목표와 구조

- 수익 구조: 사진·캐러셀 보너스는 **초대제 테스트**. 순서는 고정이다:
  **계정 자격 (프로페셔널·정책 청결) → 실적 (한국 기준 월 100만 조회 수준 유지) → 초대 후보군 → 초대 (Meta 선정, 무작위 요소 있음) → 활성화·정산**
- 따라서 운영 목표는 "초대 보장"이 아니라 **후보군에 들어간 상태를 유지하는 것**이다.
- 단가 감각 (자료 캡처 기준): 조회 100만 ≈ $110~$180. 수익은 바이럴 편차가 크므로 월 목표는 조회수 기준으로만 관리한다.

## 1. 계정 세팅 (커리큘럼 1주차 대응)

체크리스트:
- [ ] 프로페셔널 계정으로 전환 (크리에이터 유형)
- [ ] 프로필: 주제를 한눈에 알 수 있는 이름·소개 1줄. 업체·대행 계정으로 보이지 않게 개인 운영 형태로
- [ ] 계정 상태 확인: 설정 → 계정 상태 — 위반·제한 없음 확인. 있으면 먼저 해소
- [ ] 추천 가능 상태 확인: 콘텐츠가 추천에 뜰 수 있는 상태인지 (계정 상태 화면에서 함께 확인)
- [ ] 보안: 2단계 인증, 로그인 기기 정리
- [ ] 시작 전 프로페셔널 대시보드에서 보너스 메뉴 유무 확인 (이미 초대가 와 있는 계정도 있다)

원칙:
- 새 계정은 방향 없이 올리는 게시물이 가장 해롭다 (전자책 5장). 첫 게시물부터 정한 넓은 주제·형식을 반복한다
- 수익화 제한 방지의 기본은 세팅이 아니라 게시물 쪽이다 — 6절 검수를 세팅보다 중요하게 본다

## 2. 주제 선정 (1주차 대응)

**운영 스타일 (2026-10-21 HW 확정)**: 이야기는 **감동적이거나 귀여운** 이야기가 중심이다. 자극·충격 위주 소재는 조회수가 보여도 고르지 않는다. 이미지는 최대한 귀엽게 — 밝고 따뜻한 색감, 사랑스러운 표정과 구도. 단, 귀엽게 만들려고 사실을 바꾸지는 않는다 (R6).
**확정 주제: 동물. 확정 빈도: 1일 1게시.**
**운영 형식 (2026-10-21 전환): 스토리형 캐러셀 10장 안팎(8~12장)이 주력** — 1장 후킹 → 전개 → 결말, 장마다 그 장면의 이미지와 이야기 문장 (제작기 FR-12). 무료 전자책은 "한 장짜리 후킹 이미지"와 "캐러셀형 정리 이미지"를 모두 유효 형식으로 명시한다(p.15); 구체 구성법은 유료 영역이라 자료에 없어 운영자가 정한 것으로, 캐러셀을 기본값으로 삼는 이유는 넘겨보기·저장·체류가 이 모델의 핵심 변수이기 때문이다.

**운영 판단 위임 (2026-10-21 HW)**: 이 운영에서는 HW의 즉흥적인 방향 지시와 돌쇠의 판단·방법론(강의+공식 정책+실측 추이)이 충돌하면, 돌쇠의 판단 쪽으로 진행한다. HW에게 조정 내용을 보고하되, 매번 허락을 구하지는 않는다. 단 두 가지는 유지한다: 게시 건별 승인(반자동 구조)과 계정 자격을 위협하는 실험 금지.
**학습 루프**: 게시물 반응(도달·좋아요·댓글)과 계정 추이(조회·팔로워)를 보며 소재 선택·카피 구조·게시 빈도·시간을 계속 조정한다. 조정은 가설→적용→측정으로 남긴다 (성과 기록 활용). 빈도 1일 1건도 고정이 아니라 시작값이다 — 추이가 좋으면 2건 전환을 판단해 적용하고 보고한다.

- 넓은 주제 15개 중 계정당 1개로 시작: 운동 / 동물 / 우주 / 음식·요리 / 건강 / 연예·남녀관계 / 가족 / 직장 / 돈·경제 / 자동차·교통 / 군대·남자공감 / 여행 / 학교·학창시절 / 결혼 / 소비·생활
- 선정 3질문 (시크릿노트): ① 누구나 1초 만에 이해하는가 ② 공감 모수가 충분한가 ③ 해외 소재가 계속 나오는가 — 셋 다 예일 때만 채택
- 주제 안에서 소재를 고른다. 주제를 좁은 종목으로 고정하지 않는다 (예: 테니스가 아니라 운동)

## 3. 소재 소싱 (2주차 대응)

강의는 "해외에서 이미 터진 콘텐츠 찾는 법"을 가르치는데, 판정 기준은 공개 자료로 재구성 가능하다:

- 소스 유형: 해외 뉴스 매체의 화제 기사, 해외 커뮤니티 화제 게시물, 해외 정보형 계정의 바이럴 게시물
- 채택 기준 (전부 충족):
  1. 이미 검증됨 — 원본에서 조회·공유·댓글 반응이 눈에 띄게 큰 것. **지표 수치를 후보 메모에 반드시 기록한다** (예: 원본 영상 조회수, 기사 공유 수). "유명한 이야기 같다"는 감으로는 채택하지 않는다. 고전적 스토리(하치코 류)는 검증된 상수 소재로 보되, 신규 소싱은 현재 플랫폼 지표가 붙은 것만 올린다
  2. 한국에서 통함 — 문화 번역이 필요 없는 보편 공감 소재 (2절 3질문 재적용)
  3. 사진 1장으로 이야기가 됨 — 영상을 캡처해야만 성립하는 소재 제외
  4. 권리 상태 기록 가능 — 출처를 특정할 수 없는 소재는 버린다
- 기록 양식 (제작기 FR-1과 동일): 출처 URL / 원본 언어·국가 / 권리 상태 / 핵심 사실 메모
- 버리는 기준: 선정·폭력·혐오·단정 의학·범죄 미화 소재는 조회수가 보여도 제외 (6절)

## 3.5 사진 확보 경로 (우선순위)

1. **권리 확인된 원본** — 사용 조건이 명시된 소스 (공식 채널의 재배포 허용, 라이선스 구매 등)
2. **AI 재생성** — 원본을 쓸 수 없으면 스토리의 장면을 AI로 새로 그린다 (제작기 FR-11). 출처에 원본 스토리를 강제 기록한다 (내부 기록 강제). 캡션에는 AI 재구성 표기를 넣지 않는다 — 2026-10-21 HW 지시. 실존 인물의 얼굴·특정 브랜드 로고는 그리지 않는다
3. 위 둘 다 안 되면 그 소재는 버린다. "남들도 다 쓰니까"는 기준이 아니다

## 4. 제작 (2·3주차 대응)

- 제작기로 수행: 핵심 사실 확정 → 후킹 카피 (규칙 R1~R6, 15~28자) → 템플릿 합성 → 검수
- 카피 변환의 요지 (시크릿노트): 직역 금지. 결과·반전을 앞으로, 사진이 보여주는 정보는 삭제, 구어체로
- 하루 제작량을 배치로 묶는다 (예: 주 1회 몰아서 제작 → 매일 게시). 지속 가능성이 조회수보다 먼저다

## 5. 게시 운영

- 빈도: 매일 게시가 누적 조회에 유리하다는 것이 수강생 사례 캡처의 유일한 운영 힌트 ("매일매일 올리는 게 맞네요"). v0.1 기준값은 **1일 1게시**, 운영 데이터가 쌓이면 조정한다
- **게시 시간: 한국 저녁 18:00~21:00 사이 매일 랜덤 (고정 시간 금지, 2026-10-21 HW)** — 근거: 대규모 연구들(Buffer 960만 건 분석 등)에서 저녁 시간대가 일관되게 강세이고, 국내 가이드도 사진·슬라이드 게시물의 저녁 참여·저장을 높게 본다. 원리는 마법이 아니라 초기 반응 속도다. 단 팔로워가 적은 계정은 시간대 효과가 상대적으로 약하다. 큐 등록 시 scheduled_for가 18:00~21:00 안에서 랜덤으로 추첨되고(지났으면 내일 다시 추첨), 저녁 게시 작업이 승인된 항목을 그 시각에 게시한다
- **주간 배치 컨펌 (2026-10-21 HW 지시)**: 승인은 건별이 아니라 **주 단위 일괄**로 받는다. 운영자가 다음 7일분 캐러셀을 완성해 한 번에 프리뷰하면 HW가 일괄 컨펌하고, 이후 7일간은 컨펌된 항목만 매일 scheduled_for(해당 날짜 18:00~21:00 랜덤)에 자동 게시한다. 컨펌되지 않은 항목은 게시하지 않는다. 배치 제작 중에도 건별 기준(소싱 지표·검수 게이트)은 그대로 적용한다
- **검수·컨펌 창구는 운영 채팅 하나로 고정 (2026-10-22 HW 지적)**: 프리뷰와 컨펌은 운영이 이뤄지는 채팅에서 운영자에게 직접 받는다. 다른 채널(메인챗 옵션 선택 등)로 전달된 결정은 게시 시점 같은 참고 정보일 뿐, 검수를 대체하지 않는다. 프리뷰 컨펌 없이 게시 단계로 진행하지 않는다
- **게시 결과 불확실 시 재시도 금지 — 먼저 계정 확인 (2026-10-22 하치코 사례)**: instagram-cli post-feed가 로컬에서 강제 종료돼도 서버 쪽 쓰기는 살아 있어 실제 게시가 완료될 수 있다 ("equivalent connector write is already running" 오류가 그 신호). 이때 재시도하면 중복 게시 위험이 있으므로, 반드시 계정 게시물 목록을 먼저 조회해 게시 여부를 확인한 뒤에만 기록·재시도를 결정한다
- 캡션: 카피를 반복하지 말고 사실 보충 1~2줄 + 주제 해시태그 소수. 참여 유도 문구("좋아요 눌러주세요" 류) 금지 — 정책상 지급 제외 사유
- 게시 후 금지 행동 (공식 지급 제외 규칙):
  - 게시물 삭제 (지급이 함께 사라짐)
  - 광고 부스트 (부스트한 게시물은 보너스 제외)
  - 공동 게시(콜라보) — 보너스 지급 대상 아님
  - 조회수·반응 구매 — 해당 게시물 지급 무효 + 계정 리스크
- 브랜디드 콘텐츠(협찬 표시 게시물)는 보너스 대상이 아니다. 협찬을 받을 단계가 되면 보너스와 분리해 판단한다

## 5.5 반자동 운영 루프 (2026-10-21 HW 결정)

- 제작·검수는 제작기가, 게시는 운영자(사용자 또는 연결된 에이전트)가 맡는 반자동 구조
- 흐름: 검수 통과 → 게시 큐 등록 → 운영자가 연결된 인스타 계정으로 게시 (게시마다 승인) → 게시 URL을 큐에 기록 → 소재가 게시완료로 전이
- **파일럿 없음 (2026-10-21 HW 결정)**: 계정은 처음부터 본격 상업 운영으로 간다. 별도 파일럿 구간을 두지 않는다. (인스타의 시험 릴스(Trial Reels)는 릴스 전용 기능이라 사진 게시에는 해당 없음)
- **게시 직전 승인 (건별)**: 운영자는 게시 직전 최종 렌더 이미지와 캡션 전문을 사용자에게 보여주고 승인을 받는다 — 승인 없는 게시 없음
- 리듬: 1일 1게시 (5절 기준값). 큐에 쌓인 순서대로 게시한다
- 성과: 게시 후 조회수를 소재에 기록하고, 계정 지표는 연결 도구로 주 1회 확인해 월 100만 라인과 비교한다
- 무인 자동 게시·자동 소싱은 하지 않는다 (계정 자격 보호가 수익보다 우선)

## 6. 정책·검수 (4주차 대응)

게시 전 금지 8 (시크릿노트 + 공식 정책):
1. 원본 권리 없는 불펌 — 재가공은 필수지만 재가공이 권리를 만들지는 않는다. 출처 기록 + 변형(구성·문장·맥락 변경) 수준을 지킨다
2. 선정적 신체 표현
3. 폭력·잔혹 묘사
4. 혐오·차별·조롱
5. 단정적 의학 정보
6. 범죄·약물 소재
7. 참여 유도 낚시
8. 반복·저품질 (워터마크 남은 소재, 동일 문구 반복, 차별성 없는 대량 게시)

계정 보호 원칙:
- 집합(aggregator) 계정으로 보이지 않기: 원본 재배포가 아니라 "선정 + 한국식 편집 + 일관된 주제"라는 편집 실체를 유지한다. 릴스 보너스 규칙이 aggregator를 명시적으로 제외한다는 점을 사진 보너스에도 준용한다 (가정 — 9절)
- 경고·제한이 뜨면 즉시 게시 중단 → 사유 해소 → 재개. 무리한 이의신청 반복 금지

## 7. 모니터링

- 주 1회: 프로페셔널 대시보드 — 보너스 초대 유무 확인. **초대는 기한이 있고 무응답 시 만료된다**
- 월 단위 기록: 월 조회수 (한국 기준 100만 라인 대비), 게시물별 조회수 상위·하위 패턴
- 패턴 학습: 터진 게시물의 주제 세부·카피 구조를 기록해 다음 소싱 기준에 반영한다

## 8. 초대 이후 절차 (4주차 대응)

1. 대시보드에서 초대 확인 → **기한 내 활성화** (온보딩 완료)
2. 정산 계좌 등록: 미등록 상태에서는 도구당 $500, 합계 $1,500까지만 적립되고 6개월 내 미등록 시 몰수 (공식 안내)
3. 세금 (한국, 일반 안내 — 개별 신고는 본인 판단): 보너스 수입은 사업소득/기타소득 성격으로 종합소득세 신고 대상이 될 수 있다. 반복·계속적 수입이면 사업자등록 검토. 정산 내역(반월 단위)을 그대로 기록해 두는 것이 준비의 전부다

## 9. 모르는 것 — 직접 운영하며 검증할 가설

| # | 가설/미확인 | 확인 방법 |
|---|---|---|
| 1 | 월 100만 기준이 "3개월 연속"인지 "평가 시점"인지 | 일본 사례(매월×3개월)와 공식 규칙표(월 최소)만으로 확정 불가. 운영 중 초대 사례로 역추정 |
| 2 | 사진 보너스에도 aggregator 제외가 적용되는지 | 공식 규칙은 릴스에서 명시. 사진은 미명시 — 안전하게 준용 |
| 3 | 최적 게시 시간·요일 | 공개 근거 없음. 게시 기록 × 조회수로 자체 측정 |
| 4 | 계정당 주제 1개 고정이 실제로 유리한지 | 전자책의 주장. 멀티 주제와 비교 데이터 없음 |
| 5 | 다계정 운영의 안전선 | 강의 4주차 항목이나, Meta는 다계정 자체보다 정책 위반·스팸 신호를 본다. v0.1에서는 단일 계정 전제, 확장은 데이터 쌓인 뒤 별도 판단 |
| 6 | 강사의 소싱처·제작기 내부 방식 | 비공개. 이 플레이북은 동등 기능 재구성이며 동일물이 아니다 |
